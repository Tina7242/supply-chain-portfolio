 📦 Supply Chain Analytics Portfolio

Three end-to-end analytics projects covering demand forecasting, supplier
performance, and logistics delay analysis — using Python, SQL (BigQuery),
Power BI, and Tableau.

## Projects

### 📈 [Demand Forecasting & Inventory Health Dashboard](./project1-demand-forecasting)
Forecasts product demand and flags reorder risk using a time-series model,
BigQuery-based safety stock calculations, and a Power BI dashboard.

### 🏭 [Supplier Performance & Risk Scorecard](./project2-supplier-scorecard)
Scores 5 suppliers on fulfillment rate, defect rate, compliance, and cost
savings using BigQuery and Tableau.

### 🚚 [Logistics & Shipment Delay Analytics](./project3-logistics-analytics)
Cleans a real-world 25,000-row shipment dataset (including a data
corruption fix) and identifies weather as the dominant driver of delivery
delays, using Python, BigQuery, and Power BI.

## 🛠️ Tools
Python · SQL (Google BigQuery) · Power BI · Tableau
